🐍 My First Python Program

📖 Description

This is my first Python program. It introduces me and demonstrates the basics of Python programming, including printing text, using variables, and displaying information on the screen.

✨ Features

- Displays my name
- Displays my age
- Shows my favourite colour

▶️ How to Run

1. Install Python 3.
2. Download or clone this project.
3. Open the project in your preferred code editor.
4. Run the Python file:
   python main.py
